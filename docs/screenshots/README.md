# Screenshots

Image assets used by the project [`README.md`](../../README.md#screenshots).

| File | Description |
|------|-------------|
| `app-icon.png` | App icon (128px transparent PNG) shown in the README header. |
| `tray-icon.png` | The tray icon in the notification area with tooltip. |
| `quick-exclude.png` | Quick Exclude submenu — live window list with checkmarks and process icons. |
| `always-exclude.png` | Always Exclude submenu — persistent per-process rules. |
| `settings.png` | Settings submenu — hotkey toggle, change hotkey, run at startup, restart as admin. |
| `hotkey-picker.png` | Hotkey picker dialog. |
| `about.png` | About dialog. |
| `demo.gif` | Animated demo: hotkey toggling a window out of Alt+Tab. |

The app icon source is [`AltTabExcluderIcon.svg`](../../AltTabExcluderIcon.svg) at the repo root. The multi-size `app.ico` (16/32/48/256, 32-bit RGBA) is generated from it and embedded in the project at `src/AltTabExcluder/assets/app.ico`.
