# Screenshots

Save the following images here so the embeds in the project
[`README.md`](../../README.md#screenshots) render.

| File | What to capture |
|------|-----------------|
| `tray-icon.png` | The tray icon in the notification area, tooltip visible (shows the active hotkey). |
| `quick-exclude.png` | The Quick Exclude submenu — live window list with checkmarks and process icons. |
| `always-exclude.png` | The Always Exclude submenu — persistent per-process rules, with a separator for non-running saved rules. |
| `settings.png` | The Settings submenu — hotkey toggle, change hotkey, run at startup, restart as admin. |
| `hotkey-picker.png` | The Hotkey Picker dialog mid-capture. |
| `about.png` | The About dialog. |
| `hotkey-demo.gif` | Animated GIF: focus a window, press `Win+Alt+X`, show it dropping out of Alt+Tab, then restore. |

Tips:

- Use a screen recorder (e.g. ShareX, Snagit, or the built-in Snipping Tool's
  video mode) for the GIF.
- Crop tightly around the menu/dialog; a transparent or solid background both
  work.
- Keep PNGs under ~200 KB if possible (downscale if needed).
